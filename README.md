# hotelbokking

A responsive hotel discovery and booking frontend built with vanilla HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No dependencies or build step are required.

## Features

- Responsive hotel discovery page with search, destination filtering, and stay categories.
- Check-in and check-out date validation and a guest selector.
- Hotel cards with favorites and accessible feedback.
- Mobile navigation and a responsive layout.
